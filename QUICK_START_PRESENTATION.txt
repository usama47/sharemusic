PAKISTAN NATIONAL ANTHEM SYNC — QUICK START

1. On the SERVER laptop:
   npm install
   npm start

2. Run ipconfig and find the server's IPv4 address, e.g. 192.168.1.25.

3. On the server:
   http://192.168.1.25:3000/admin

4. On every floor laptop:
   http://192.168.1.25:3000/floor
   Click JOIN & ENABLE AUDIO once.

5. For an extended display, click OPEN TRIBUTE DISPLAY FOR SECOND SCREEN.
   If the browser cannot automatically move it, drag the new window to the
   external monitor and press F11/fullscreen.

6. In Admin:
   START = one fresh synchronized run. It will NOT restart a running/paused run.
   RESET & START = throw away the current position and start again from 00:00.
   STOP = return all clients to the waiting screen.
   PAUSE / RESUME = pause and continue the same master timeline.

IMPORTANT:
- Other laptops must use the SERVER laptop's LAN IP, never localhost.
- All laptops should be on the same LAN/Wi-Fi.
- Click JOIN & ENABLE AUDIO before the admin starts. This is required by browser
  autoplay security.
- The bundled anthem MP3 is 82.938776 seconds. The 10-minute visual presentation continues after
the anthem ends. Dil Say Pakistan begins at 02:22.939, exactly one minute after the anthem ends,
and plays on the MAIN/audio laptop while all displays follow the same master clock.

ADMIN FLOW:
JOIN ALL DEVICES -> VERIFY READY/AUDIO READY -> START.
To run it again from the beginning, press RESET & START.


DISPLAY ASSET UPDATE — 13 AUG 2026
-----------------------------------
This build uses the supplied Pakistan flag on the MAIN screen and individual 1920x1080 photographs
on the EXTENDED/Tribute screen. No collage/poster is used for slideshow playback.

There are 50 timed photo slots across 10 minutes:
1940s, 1950s, 1960s, 1970s, 1980s, 1990s, 2000s, 2010s, 2020s/2026, and 2047 future.
Each extended laptop gets a different deterministic random order inside each decade while the
timing remains identical on every connected laptop.

MAIN:
  /floor
  -> Join & Enable Audio
  -> wait for admin START
  -> supplied flag image fills the display
  -> use Enter Fullscreen before START, or the FULL SCREEN button/double-click during presentation

EXTENDED:
  /floor?screen=extended
  -> open from the main waiting screen with "Open Tribute Display for Second Screen"
  -> move it to the extended monitor if the browser cannot place it automatically
  -> use Enter Fullscreen or the FULL SCREEN button

IMPORTANT:
A browser cannot silently take over a specific physical monitor on every machine. The app uses
the Window Management API when available and otherwise requires the user to move the tribute
window to the second monitor once. This is a browser security limitation, not a sync limitation.

The new supplied flag is intentionally NOT warped by JavaScript. It already contains realistic
fabric folds, so the app only applies a very subtle cinematic zoom. This prevents the crescent,
star, and white stripe from becoming distorted.

The supplied posters are scheduled across the full 82.939-second anthem:
01 1940s -> 02 1950s -> 03 1960s -> 04 1970s -> 05 1980s ->
06 1990s -> 07 2000s -> 08 2010s -> 09 2020s -> 10 2047.
